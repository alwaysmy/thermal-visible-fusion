# Third party dependencies and private vendor materials

This repository contains original application/reference source. Dependency managers fetch external libraries; their licenses continue to apply.

- OpenCV / opencv-python-headless: OpenCV is Apache-2.0; binary wheels have additional third-party notices. Official sources: https://opencv.org/license/ and https://github.com/opencv/opencv-python
- NumPy: BSD-3-Clause and bundled-component notices. Official source: https://numpy.org/doc/stable/license.html
- pytest: MIT. Official source: https://github.com/pytest-dev/pytest/blob/main/LICENSE
- Android APIs/build tooling: downloaded separately from official Android/Google repositories, governed by their own licenses
- Gradle wrapper, if included under android/: fetched from the official Gradle project and governed by its included notice/license; the distribution is checksum-verified

No vendor SDK, native library, official demo APK, vendor documentation archive, license key, private capture or account credential is intended for redistribution here. Vendor API compatibility will be documented after static inspection. Source publication does not imply permission to redistribute vendor binaries.

This project has not yet selected a license for its original source. Public visibility alone does not replace a license grant.
